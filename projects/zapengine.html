Overview

For BUAS Y2 block C,
We were tasked to make a cross platform game engine for PC and PS5

I was responsible for rendering on both platforms,
as the only graphics programmer in a team of 6 other engine programmers.

We then had to use this engine in a cross discipline team to make a game.

My Role

WIP: still have to write/show actual sections, here is a list of what I did for now.

I created the renderer for the engine, with feature parity on both platforms
OpenGL and PS5.

  • PBR Renderer, PBR Materials, shadows, and IBL
  • Particle system, with mesh shaders for rendering. Updates on CPU but performant and extensive
  • Post processing, with: Bloom, Toon shader, Outlines and Mesh blending
  • UI System (with an editor, masking, animations)
  • Support for multiple viewports (pc only)
  • Flight stick support with FFB, (directinput, pc only)

Some further systems I interacted with and did something on but did not make

  • Custom shaders with Slang, (added usability, default variables, hot reloading, PBR)
  • Lightprobes (build on top of IBL system)
  • FMOD (fixed spatial audio)
  • Angelscript (worked with and binded C++ functions/variables)
